MiniMobile - Mac판 (Apple 실리콘 / 인텔 공용)
==============================================

Android 앱, Windows판과 같은 에뮬레이터로 KTF / LGT / SKT / BREW / J2ME
게임을 실행합니다. 화면과 메뉴, 키는 Windows판과 같습니다.

설치
----
1. MiniMobile-mac.dmg를 열고 MiniMobile을 응용 프로그램 폴더로 끌어다
   놓습니다.
2. 처음 한 번은 그냥 열리지 않습니다. (Apple 개발자 서명이 없는 앱이라
   "확인되지 않은 개발자" 창이 뜹니다.)
   - macOS 14 이하: MiniMobile을 Control-클릭(또는 오른쪽 클릭) → 열기 →
     열기.
   - macOS 15 이상: 한 번 열어 본 뒤 시스템 설정 → 개인정보 보호 및 보안
     맨 아래의 "MiniMobile" 옆 "그래도 열기"를 누릅니다.
   - "손상되었기 때문에 열 수 없습니다"가 뜨면 터미널에서 한 번:
         xattr -dr com.apple.quarantine /Applications/MiniMobile.app
3. 게임 파일(.zip, .jar)을 창에 끌어다 놓거나 games 폴더에 넣습니다.
   (게임 목록에서 fn+F2를 누르면 games 폴더가 Finder로 열립니다.)

키 (기본값, 설정에서 바꿀 수 있음)
---------------------------------
Mac 키보드에서 F 키는 fn을 함께 누릅니다 (시스템 설정 → 키보드에서
"F1, F2 등의 키를 표준 기능 키로 사용"을 켜면 fn 없이도 됩니다).
Del은 fn+delete 또는 ⌘+delete입니다.

게임 목록 (게임 아이콘을 옆으로 넘기며 고릅니다)
    좌/우 (위/아래)      게임 고르기
    return               실행
    tab, 또는 글자 입력  검색 (이름 일부나 초성: ㅎㄱ → 학교가는길)
                         검색 중 delete 지우기, esc 검색 닫기
    esc                  메뉴 (설정, 배속, 소리, 세이브 관리, 삭제, 화면)
    ⌘+delete             고른 게임 삭제 (묻고 나서 지웁니다)
    F2                   games 폴더 열기
    ⌃⌘F                  전체화면 / 창
    ⌘Q                   끝내기
    마우스·트랙패드      위쪽 탭으로 통신사별 보기, 옆 아이콘 클릭으로 고르기,
                         가운데 아이콘 클릭으로 실행, 스크롤로 넘기기

게임 중
    방향키                방향키
    return, space         확인
    delete                취소
    왼쪽 shift, [         왼쪽 소프트키
    오른쪽 shift, ]       오른쪽 소프트키
    숫자 0~9, 키패드 0~9  숫자 키
    -, 키패드 *           *
    =, 키패드 /           #
    F1 / F2               통화 / 종료
    esc, 오른쪽 클릭      일시정지 메뉴
    F5 / F6               느리게 / 빠르게 (배속)
    F7 / F8               소리 줄이기 / 키우기
    ⌃⌘F                   전체화면 / 창

게임패드를 연결하면 패드로도 할 수 있습니다 (Xbox, PlayStation,
Switch Pro 등 macOS가 알아보는 패드).

메뉴
----
게임 목록이나 게임 중에 esc를 누르면 열립니다. 게임 중에는 메뉴가
열린 동안 게임이 멈춰 있습니다. Windows판과 같습니다.

    키보드 배치 / 패드 버튼  폰 키를 고른 뒤 쓸 키나 버튼을 누릅니다.
    프리셋                  키보드와 패드 배치를 함께 저장합니다.
    이 게임에 프리셋 고정    그 게임을 실행할 때마다 그 프리셋으로 바뀝니다.
    배속                    게임마다 따로 기억합니다.
    화질                    기본 / 도트 / HQ2X
    소리                    0%~100%, 모든 게임 공통. M으로 음소거.
    세이브 관리              (게임 목록에서만) 내보내기 / 가져오기 / 지우기.
                            Android 앱, Windows판의 세이브 zip과 호환됩니다.
    이 게임 삭제             게임만, 또는 세이브까지 함께 지웁니다.
    화면                    창 2배 / 3배 / 4배 / 전체화면

지운 게임 파일과 세이브는 휴지통으로 가므로 "되돌려 놓기"로 되살릴 수
있습니다.

파일
----
게임과 세이브, 설정은 앱이 아니라 아래 폴더에 있습니다. 앱을 새로 받아
덮어써도 그대로 남습니다.

    ~/Library/Application Support/MiniMobile/

    games/                게임 파일
    data/                 세이브 (Android 앱과 같은 구조)
    saves/                내보낸 세이브 zip
    controls.txt          지금 키 / 버튼 설정
    presets/              프리셋
    last_game_log.txt     마지막 게임의 에뮬레이터 로그

Finder에서 이 폴더로 가려면 이동 → 폴더로 이동(⇧⌘G)에 위 경로를 넣거나,
게임 목록에서 F2를 누릅니다.

참고
----
앱 안의 SDL2.framework는 SDL 라이브러리(zlib 라이선스)입니다.
