MiniMobile - Windows판 (64비트)
================================

Android 앱과 같은 에뮬레이터로 KTF / LGT / SKT / BREW / J2ME 게임을
실행합니다.

실행
----
1. 압축을 풀어 MiniMobile 폴더를 원하는 곳에 둡니다.
   (MiniMobile.exe와 SDL2.dll은 같은 폴더에 있어야 합니다.)
2. MiniMobile.exe를 실행합니다.
   처음 실행할 때 "Windows의 PC 보호" 창이 뜨면
   "추가 정보" → "실행"을 누르세요. (서명하지 않은 프로그램이라 뜹니다.)
3. 게임 파일(.zip, .jar)을 창에 끌어다 놓거나 games 폴더에 넣습니다.

키 (기본값, 설정에서 바꿀 수 있음)
---------------------------------
게임 목록
    위/아래              게임 고르기
    Enter                실행
    Esc                  메뉴 (설정, 배속, 세이브 관리, 삭제, 화면, 종료)
    Del                  고른 게임 삭제 (묻고 나서 지웁니다)
    F2                   games 폴더 열기
    F11                  전체화면 / 창

게임 중
    방향키                방향키
    Enter, Space          확인
    Backspace             취소
    왼쪽 Shift, [         왼쪽 소프트키
    오른쪽 Shift, ]       오른쪽 소프트키
    숫자 0~9, 키패드 0~9  숫자 키
    -, 키패드 *           *
    =, 키패드 /           #
    F1 / F2               통화 / 종료
    Esc                   일시정지 메뉴
    F5 / F6               느리게 / 빠르게 (배속)
    F11                   전체화면 / 창

게임패드를 연결하면 패드로도 할 수 있습니다 (휴대용 게임기판과 같은
배치: A 확인, B 취소, SELECT를 누른 채로 숫자 키).

메뉴
----
게임 목록이나 게임 중에 Esc를 누르면 열립니다. 게임 중에는 메뉴가
열린 동안 게임이 멈춰 있습니다.

    키보드 배치 바꾸기     폰 키마다 키보드 키를 두 개까지 정합니다.
                          Enter를 누른 뒤 쓸 키를 누르면 되고, Del로
                          비웁니다. 다른 폰 키에 쓰이던 키는 옮겨 옵니다.
    패드 버튼 배치 바꾸기  게임패드 버튼마다 폰 키를 고릅니다.
    프리셋                키보드와 패드 배치를 함께 저장합니다.
                          ◀▶로 바로 바꾸고, Enter로 목록을 엽니다.
                          목록에서 Enter 불러오기, F2 덮어쓰기,
                          Del 지우기(두 번).
    이 게임에 프리셋 고정  그 게임을 실행할 때마다 그 프리셋으로 바뀝니다.
    배속                  0.5배~4배. 게임마다 따로 기억합니다.
                          게임 중에는 F5 / F6으로도 바꿉니다.
    세이브 관리            (게임 목록에서만)
                          내보내기: saves 폴더에 "게임 이름 세이브 날짜
                            시각.zip"으로 저장합니다. 내보낼 때마다 새
                            파일이 생깁니다.
                          가져오기: saves 폴더의 세이브 zip을 고릅니다.
                            지금 세이브는 덮어쓰기 전에 saves 폴더에
                            "(가져오기 전)"으로 자동 보관합니다.
                          세이브 지우기
                          Android 앱이 내보낸 세이브 zip과 서로 호환됩니다.
    이 게임 삭제           (게임 목록에서만, Del 키와 같음)
                          게임만 지우거나 세이브까지 함께 지웁니다.
    화면                  창 2배 / 3배 / 4배 / 전체화면

지운 게임 파일과 세이브는 Windows 휴지통으로 가므로 되살릴 수 있습니다.

파일
----
모두 MiniMobile.exe와 같은 폴더에 있습니다.

    games\                게임 파일
    data\                 세이브 (Android 앱과 같은 구조)
    saves\                내보낸 세이브 zip
    controls.txt          지금 키 / 버튼 설정
    presets\              프리셋
    last_game_log.txt     마지막 게임의 에뮬레이터 로그

참고
----
SDL2.dll은 SDL 라이브러리(zlib 라이선스)입니다. README-SDL.txt를
보세요.
